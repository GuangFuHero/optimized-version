# 管理後台系統需求說明 PRD — ManagerEnd

本文件定義了 **島嶼守望 Wanguard** 後台管理系統（ManagerEnd）的系統功能與權限架構需求。

---

## 1. 登入與使用者系統 (Auth & Profile)

### 1.1 身份認證 (Auth)
* **前台使用者登入**：
  * **自有帳號系統**：支援 Email 與手機簡訊（SMS）登入。
  * **第三方登入**：支援 Google (Gmail) 與 Line 登入。
* **後台管理人員登入**：
  * 使用 **究平安 (SSO)** 系統。取得基於角色存取控制（RBAC）的分級權限後，登入並導向管理後台首頁。

### 1.2 個人檔案 (User Profile)
* **內部提醒通知 (Notifications)**：非主動推播，當使用者點開或開啟網頁頁面時即更新。支援 Safari, Chrome 等核心瀏覽器。
  * **任務配對提醒**：當有志工承接任務時，任務發起者會收到通知。
  * **審查結果通知**：前台使用者提出的資料修改建議審查結果。
  * **角色升等提醒**：前台使用者申請變更為後台權限之通過與拒絕通知。
* **基本資訊 (User Info)**：包含名字、暱稱 (選填)、電話、Email、後台角色身份。
* **系統使用習慣**：記錄使用者常固定（Pin）的圖層、常 Pin 的觀測站點、以及習慣關注的任務類型。

### 1.3 個人設定 (Settings)
* 帳號停用、忘記與變更密碼、修改聯繫方式與暱稱。
* 申請變更角色身份（升等或調整）。

---

## 2. 角色權限管理 (RBAC)

平台各頁面結構一致，但系統會根據使用者的 RBAC 權限動態調整控制項目的顯示狀態（例如：Data Auditor 無法看到變更角色的控制項）。

### 2.1 角色職掌

* **超級管理員 (Super Admin)**：
  * 擁有最高權限，可調整與指派所有人員的後台角色身份與帳號狀態。
* **政府單位 (Government)**：
  * 可指派專屬 NGO 至對應行政責任區域。
* **非政府組織 (NGO)**：
  * 僅能檢視被指派行政區域內的所有任務單據，並支援單據資料匯出。
* **數據審查員 (Data Auditor)**：
  * 審查可疑資訊或 AI 回報之重複單據（勾選核准或叉選拒絕），決定單據是否顯示在前台。
  * 修正前台已存在的錯誤資訊（糾錯）。
  * 新增或處理資源站點回報議題

### 2.2 成員審核功能 (Super Admin Only)
* 提供**用戶列表 (Table)**：Super Admin 具備完全編輯權限，Government 可檢視 (View only)，其餘角色無權限檢視。
* **身份調整審核**：
  * 變更帳號權限（啟用/停用/變更後台角色）。
  * 指派後台新成員：可產生專屬 **QRCode 邀請連結**，被邀請者掃描後即可加入成為成員。
  * 檢視帳號操作紀錄日誌（Audit Log）。
  * 審核佇列管理：對審核中（Pending）的變更申請進行核准或附帶理由拒絕。

## 3. 地圖與即時決策功能 (Map & Decision)

後台使用者無須切換前台，可直接在後台地圖工作台完成所有決策與配置。

### 3.1 即時決策輔助
* 整合**電線桿編號**圖層（結合 CSV 數據展現），便於快速在山區或無門牌地區定位。
* 即時顯示災害預警圖層與其他整合數據。

### 3.2 資源站管理 (Resource Station)
支援 Table + BI 表格與地圖模式一鍵切換。
* **Table + BI 表格視圖**：
  * 統計不同站點類型的數量（支援依地區、類型、成立時間、營運狀態進行 Filter）。
  * 站點操作歷史紀錄（記錄站點的開設者、細節變更人等）。
* **地圖視圖**：整合 OpenStreetMap API 或衛星圖資。
* **前台修改建議審查**：審查前台用戶提交的站點修改建議（核准/拒絕/直接調整），此項限 Data Auditor 與 Super Admin 進行。
* **編輯動作 (Action)**：站點的新增、編輯與刪除（刪除限 Super Admin 進行）。

### 3.3 任務管理 (Ticket Management)
支援 Table + BI 表格與地圖模式一鍵切換。
* **Table + BI 表格與統計**：
  * 任務總量統計與進度篩選。
  * 志工數量統計：每日媒合人數、累計承接數、目前的**志工缺口**（如：每日缺口 = 300 真實志工人數 / 3000 志工需求量），當缺口過大時給予紅色視覺警示。
  * 任務變更歷史紀錄（限 Admin/Auditor/Gov）。
* **地圖視圖與劃區指派**：
  * 與前台共用 OpenStreetMap 底圖，方便點擊檢視。
  * **Government 劃區規劃**：支援在地圖上以滑鼠**拉框選取區域**，將該劃定區塊的任務整體指派給指定 NGO（如：A 區劃給慈濟、B 區劃給壯闊台灣）。
* **AI 疑似重複任務比對**：
  * AI 自動標記可能重複的申報，Data Auditor 可並排對比兩筆資料欄位，進行「合併」、「保留兩者」或「刪除某筆」決策。
* **編輯動作 (Action)**：修改欄位、變更狀態、刪除（限 Admin）、以及一鍵啟動「立刻救援」極高優先級機制（限 Admin）。

---

## 4. 緊急公告系統

* **前台公告編輯**：在災情啟動或突發事件時編輯並在前台置頂展開。
* **後台公告編輯**：向所有後台工作人員與 NGO 發佈協調事項公告。
* 支援公告發佈前預覽。
