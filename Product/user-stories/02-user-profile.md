# User Stories — 個人檔案 (User Profile)

本文件是由 `product/prd/02-user-profile/prd.md` 提取出的 User Stories。

* **As a** 任務發起者，**I want** 當志工承接我的任務時收到通知，**so that** 我知道任務已被跟進，不需要主動追蹤。
* **As a** 前台使用者，**I want** 知道自己提交的資料修改建議審查結果，**so that** 我能確認平台資訊是否已被更正。
* **As a** 後台管理人員，**I want** 系統記住我常用的圖層與觀測站點，**so that** 每次登入不需要重新設定工作環境。
