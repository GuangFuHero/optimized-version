# Legacy Member Management engineering package

**Status:** legacy-unreconciled

This directory preserves the former Backend Administration engineering specification and its self-checklist. It is historical evidence, not a current product or technical contract.

The package combines Team/member management with operations dashboards, system configuration, performance monitoring, exports, authentication, RBAC, request moderation, and unrelated domain features. Its role model and scope do not align cleanly with the canonical separation between Identity and Account, Access Control, and Member Management.

Do not cite these files from a product-area README or Version manifest. Reintroduce a technical contract only after comparing it with current code and the owning Feature.
