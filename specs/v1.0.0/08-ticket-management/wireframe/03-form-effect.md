# 03 — 欄位設定會怎麼反映到表單

選做法之前，先看它出來的表單長怎樣。**這才是現場真正會碰到的東西。**

情境同前：水災，管理員已經加了「積水深度」。

---

## 前台民眾報案（永遠極簡）

不管選哪個做法，這裡都一樣——這是既有決定「報案不卡關」，自訂欄位一律不出現在民眾端。

```
┌───────────────────────────────────┐
│  我要求救                          │
├───────────────────────────────────┤
│  在哪裡                            │
│  ┌─────────────────────────────┐  │
│  │ 📍 點地圖或輸入地址          │  │
│  └─────────────────────────────┘  │
│                                   │
│  需要什麼（可複選）                 │
│  ☑ 有人受困    ☐ 人力              │
│  ☐ 物資        ☐ 其他              │
│                                   │
│  怎麼聯絡你                        │
│  ┌─────────────────────────────┐  │
│  │ 姓名                         │  │
│  ├─────────────────────────────┤  │
│  │ 電話                         │  │
│  └─────────────────────────────┘  │
│                                   │
│         [    送出求救    ]         │
│                                   │
│  ⓘ 不用選災害、不用填專業欄位       │
└───────────────────────────────────┘
```

**自訂欄位在這裡一個都不會出現。** 它們是給後台補的。

---

## 舊資料的問題（做法 A 的代價）

水災結束、管理員把「積水深度」從清單移除。這時打開一張舊的水災工單：

```
┌─────────────────────────────────────────────────────────────┐
│  後台 › 工單 #d0000042（2026 花蓮水災）                       │
├─────────────────────────────────────────────────────────────┤
│  受困人數  3                                                 │
│  樓層      2                                                 │
│                                                             │
│  ？？？ 這張工單存了「積水深度 = 80」                         │
│         但欄位清單裡已經沒有「積水深度」了                     │
│                                                             │
│  該怎麼顯示：                                                │
│    (a) 照常顯示，標成唯讀「已停用欄位」                       │
│    (b) 完全隱藏，資料留在資料庫但看不到                       │
│    (c) 不准移除欄位，只能停用                                 │
└─────────────────────────────────────────────────────────────┘
```

這題要決定。我傾向 **(c) 只能停用不能刪**——停用後新表單不顯示，舊資料照常看得到，也不會有資料看不見的疑慮。

## 還沒設計的東西

不管選哪個做法，欄位清單現在都缺這些，都會直接影響上面的表單：

| 缺什麼 | 沒有的話會怎樣 |
|---|---|
| **必填** | 每個欄位都是選填，沒辦法要求「救援一定要填受困人數」 |
| **顯示名稱** | 現在只有英文代號 `people_count`，畫面上要顯示什麼中文沒地方存 |
| **排序** | 欄位出現的順序無法控制，現在是資料庫回傳什麼順序就什麼順序 |
| **驗證** | 只能限定下拉選項，沒辦法限制「樓層要 1～50」 |
| **誰能看** | 沒有欄位級的權限，無法設定「危害備註不給訪客看」 |
| **誰改的** | 沒有紀錄，管理員刪掉一個欄位沒有軌跡 |
