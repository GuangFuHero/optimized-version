# 🧩 共用元件庫模組規劃

平台採**模組化架構**，將功能拆分為 12 個職責明確的共用元件。各元件透過標準介面協作、互不直接耦合，使邊界清晰、易於維護與擴充，平台亦可依需求替換或升級特定功能，而不影響其他模組運作。

## 第一階段核心元件（1–6）

### 1️⃣ 二維（2D）底圖圖資呈現　`優先度：高`

平台所有地理資訊的呈現基礎，以互動地圖作為災區資訊的核心介面。

- **功能**：二維互動地圖，支援 OpenStreetMap 街道圖／衛星圖底圖切換；依身分與需求動態開關多圖層（資源站點、任務熱區、行政區塊）；個人釘選（pin）圖層偏好，下次進入自動還原。
- **資料輸入**：街道圖圖磚、衛星圖圖磚、資料庫 GIS 資料（站點位置、區域位置）、瀏覽器本地端偏好資料。
- **輸出成果**：可依縮放層級與座標動態載入的底圖、疊加顯示的站點與區域圖層、載入時自動還原的圖層開關與釘選偏好。
- **運作說明**：作為背景底圖與基本經緯度資訊，供任務回報、站點回報等元件嵌入使用。衛星圖磚授權由來源方開放，本元件為取用方，圖磚內容不存於統一資料庫。

### 2️⃣ 使用者登入驗證框架　`優先度：高`

所有需登入狀態功能的共同前提，提供低阻力的多元進場路徑。

- **功能**：平台原生帳號（Email 註冊）＋ 第三方社群登入（Gmail、LINE OAuth）；原生帳號密碼存於平台本身，第三方登入透過開放授權（OAuth）驗證身分，平台不儲存第三方帳號密碼及個資。
- **資料輸入**：原生帳號資料（Email、密碼）、開放授權資料（Gmail、LINE 等）。
- **輸出成果**：登入成功並取得已登入狀態；自動建立或對應帳號並建立使用者工作階段。
- **運作說明**：後續開發者可直接採用原生帳號與第三方登入，亦可自行串接其他 OAuth 機制。數位發展部之數位憑證皮夾因發證門檻較高，暫不列入預設登入選項，建議後續擴充討論。

### 3️⃣ 任務回報　`優先度：高`

救災行動的核心資料來源之一，記錄需求並保留完整操作歷史。

- **功能**：建立任務單（填表人資訊、需求描述與程度分級、影響範圍、地址地標、現場照片與連結附件）；完整操作日誌（Action Log），記錄操作人與時間，供災後復盤。
- **資料輸入**：填表人提交的任務單內容、各項操作紀錄。
- **輸出成果**：含唯一識別碼（ID）、需求類型、程度、地址、附件等欄位的任務單；可匯出供分析的操作日誌。
- **運作說明**：任務單為救災行動之資料來源，可依各災害的資料蒐集需求調整欄位。採僅追加（Append-only）資料模型，須於設計階段確立；即時同步需求建議確認實際情境後再評估。

### 4️⃣ 站點回報　`優先度：高`

與地圖元件共同運作，維護資源站點狀態的準確性。

- **功能**：前臺使用者針對資源站點提交狀態更新建議（如是否仍在運作），並可補充文字說明。
- **資料輸入**：站點識別碼及站點狀態回報內容。
- **輸出成果**：於各站點關聯最新資訊（營運狀態、文字說明等）。
- **運作說明**：地圖元件負責呈現站點位置，本元件負責維護站點狀態。因資訊暴露快速，須注意假資訊或過時資訊，透過大量志工評論（Comment）取得更新訊息。

### 5️⃣ 志工需求 / 任務媒合　`優先度：高`

任務與執行者之間的連結層，處理人力調度瓶頸。

- **功能**：志工自接任務（人數額滿自動更新為「媒合成功」）；媒合單刪除；狀態流轉「待媒合 → 媒合中 → 媒合成功」及刪單例外路徑；整段媒合歷程記入操作日誌。
- **資料輸入**：任務單資料（來自任務回報元件）、接案操作（承接／刪除）、接案操作之操作日誌。
- **輸出成果**：媒合成功或刪除後即時更新任務單狀態；可匯出的操作日誌。
- **運作說明**：依賴任務回報提供的任務單資料，並將媒合結果回寫至同一張任務單的狀態欄位。任務狀態屬有限狀態機，建議於資料模型設計階段確立所有合法狀態與轉換條件。

### 6️⃣ 單點分享　`優先度：中`

降低資訊轉傳成本，可掛載於任何頁面類型的純前端元件。

- **功能**：社群平台分享（LINE 分享對話框、臉書、Threads，透過開放 URL 規範實作，無需申請授權）；一鍵複製連結；動態產生頁面 QR Code，可下載或截圖線下流通。
- **資料輸入**：使用者觸發「分享方式」或「QR Code」操作 ＋ 目標頁面資訊（標題、描述、URL）。
- **輸出成果**：社群分享訊息與 URL、連結至目標頁面的 QR Code 圖片。
- **運作說明**：可用於任務與站點，由頁面提供標題、描述、URL 三項資料即可運作，不依賴特定資料結構。開放社交關係圖（OG）標籤若需動態產生，平台應採伺服器端渲染；複製連結與 QR Code 屬純前端實作、無外部依賴。
