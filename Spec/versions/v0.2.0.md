# v0.2.0: Identity and decision-support expansion

## Outcome

Expand the early trial with user identity management, the surrounding map decision-support experience, and emergency announcements after the initial operational loop has a usable release path.

No Feature is Released and no product area has a released baseline anchor yet.

## Scope

| Product area | Feature scope | Current status | Release evidence |
|---|---|---|---|
| Identity and Account | [`IAM-FEAT-001`](../product-areas/identity-and-account/features/IAM-FEAT-001-authentication/feature.md), [`IAM-FEAT-002`](../product-areas/identity-and-account/features/IAM-FEAT-002-user-profile/feature.md), [`IAM-FEAT-003`](../product-areas/identity-and-account/features/IAM-FEAT-003-user-settings/feature.md) | Draft | None |
| Map Decision Support | [`MAP-FEAT-001`](../product-areas/map-decision-support/features/MAP-FEAT-001-map-decision-support/feature.md) | Definition | None |

| Task Management | [`TM-FEAT-003`](../product-areas/task-management/features/TM-FEAT-003-guest-ticket-privacy/feature.md) | Draft | None |

## Relationship to v0.1.0

- Guest task privacy (`TM-FEAT-003`) is deferred from `v0.1.0`, now defined, and explicitly included in this Version.
- Zone drawing and its assignment and hazard effects moved earlier to `v0.1.0` as [`MAP-FEAT-002`](../product-areas/map-decision-support/features/MAP-FEAT-002-zone-drawing-and-effects/feature.md); `MAP-FEAT-001` covers the remaining map capabilities and depends on that behavior.
- Other v0.1.0 Features are not automatically carried into this Version; a Feature must explicitly target `v0.2.0`.
