# v0.1.0: Early trial operations

## Outcome

Provide the first usable operational loop for controlled access, member administration, resource-station information, and task coordination during an early trial.

This is an early trial Version, not a stable product contract. No Feature is Released and no product area has a released baseline anchor yet.
