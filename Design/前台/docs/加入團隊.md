## 2. 規則（🔒）

- **JOIN-101** 掃碼也要管理員核准。掃碼的好處只剩「團隊已經選好」。前台「申請管理權限」那句同步改成：「如果{teamNoun}已經給你邀請碼，掃碼會直接帶到那個團隊，不用自己找；一樣要等管理員核准。」（`js/site/site-actions.jsx`）
- **JOIN-102** 登入後頂部永遠是同一張團隊卡，讓人先確認掃到的是哪一隊。
- **JOIN-104** 登入／註冊完回到 `/invites/{token}`（#146 已做）。
- **JOIN-106** 撤回就地確認、不用彈窗；撤回後表單內容還在。
- **JOIN-109** 被拒絕過的人再掃：後端有留那筆，但邀請 API 只回審核中的 → **畫面跟第一次一樣**，不另做（AC-RE-107 可以立刻再申請）。
- **JOIN-110** 「邀請有效至」照 `expires_at` 顯示；送出後邀請到期不影響已送出的申請。
- **JOIN-112** ⑩、⑪ 的提示在表單最上方、按鈕在最下方 → **送出失敗時自動捲回最上面**讓提示進入畫面（`scrollIntoView`），焦點移到提示（`role="alert"`）。不捲的話只看到按鈕沒反應。

## 4. 附帶：「密碼已變更」通知的文字

現在寫「若非本人操作，請立即使用第三方登入進入帳號並變更密碼」，沒有 LINE／Google 的人做不到。建議改成：

> 你的密碼在 {時間} 變更了。如果不是你自己改的，請馬上到登入頁按「忘記密碼」重設，再到「帳號安全」按「登出所有裝置」。

- 「忘記密碼」每個人都能用：會改密碼的帳號一定有密碼，有密碼就一定有電子郵件或手機（帳號安全 ⑦ 規則）
- 被改密碼的人可能已經被登出、看不到鈴鐺 → 這則要寄到電子郵件／簡訊（#149 已在做）
