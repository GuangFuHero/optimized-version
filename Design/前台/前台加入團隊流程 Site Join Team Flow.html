第二版改了什麼（依後端）

  • 被拒絕後再掃＝跟第一次一樣。後端有留那筆（狀態「已拒絕」＋原因，也發了含原因的通知），但邀請頁的 API 只回「審核中」的申請；Spec 026 也寫明被拒絕或撤回可以立刻再申請。原本的 G4 拿掉。
  • 登入前看不到是哪一隊。讀邀請的 API 要登入；連結能不能用也是登入後才知道。
  • 過期和失效合成一個畫面。後端過期、不存在、團隊停權一律回同一個 404。
  • 加手機前要先確認本人（ADR-220），三種帳號三種做法（⑨）。
  • 表單多「電子郵件（選填）」與「邀請有效至」；送出後邀請到期不影響已送出的申請。
  • 拒絕一定有原因（後端規定），所以⑬照抄管理員寫的原因。

還沒定的

  • ⑬ 結果通知只有鈴鐺，還是也要發簡訊？（他可能已經關掉網頁）
  • 團隊類型的叫法：原型寫「政府／非政府組織」，#146 寫「政府單位／社福團體」，要統一一種。
  • ⑪ 的「改成自己申請（帶著填的）」需要前端把草稿帶到「申請管理權限」，#146 目前兩邊刻意不共用草稿。
