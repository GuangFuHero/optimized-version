# 沒有權限訪問此頁（403）—— 後台

> 最後更新：2026-10-20 · 分支 `sucrelindesign`
> 標 🔒 的是已裁示；標 🚨 的是設計端先定、**尚未經團隊裁示**，實作前請先確認。

## 做什麼

後台的頁面**存在**，但使用者**目前的身份**沒有權限時顯示的畫面。畫面跟「找不到這一頁」（404）是同一支元件，只是字、圖、動畫不同。

| 原型頁 | 外殼 | 檔案 |
|---|---|---|
| `後台/後台沒有權限 Forbidden.html` | 後台外殼（`WGShell`，`active="forbidden"`） | `js/admin/shell/wg-forbidden-page.jsx` ＋ `js/shared/wg-notfound.jsx` ＋ `js/shared/wg-mascot.jsx` |

### 什麼時候會走到這一頁

🔒 後台是**乾淨切**（2026-08-17 D-3）：沒權限的頁面側欄本來就不出現、按鈕不 render。所以正常操作**不會**走到這裡。會走到的只有：

- 直接打網址、書籤、別人傳來的連結
- 在某一頁從右上角切換身份，新身份看不到這一頁
- 後端 API 回 403（權限在這段期間被改了）

## 正式版實作建議（⚠️ 前端決定）

- Next.js App Router：`app/admin/` 底下的頁面在 server 端判斷權限不足時，可回傳一個 `forbidden` 狀態並在 admin layout 裡渲染這個畫面（Next.js 15 有實驗性的 `forbidden()`／`forbidden.tsx`；或自己做一個 `<Forbidden />` 元件）。重點是**保留後台 layout**（規則 1）。
- 網址不要改（不要 redirect 到 `/403`），使用者切換身份後才能就地重試。
- 「找誰」需要知道目前身份是不是團隊成員：讀目前身份的團隊角色即可，**不需要**後端回傳「需要什麼角色」。
