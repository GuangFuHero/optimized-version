# 角色與權限：誰看得到什麼

> 2026-10-16 起頂端的「原型 · 角色視角」切換列已經拿掉（使用者不會看到）。
> 工程師要確認各角色的畫面，用下面的**網址參數預覽**。本頁的表格是用這個方法逐頁實際打開記錄的，不是只抄程式。

## 怎麼預覽某個角色

在任一後台頁的網址後面加 `?as=<角色>`：

| `?as=` | 以誰登入 | 平台角色 | 所屬團隊（團隊角色） |
|---|---|---|---|
| `super` | 林承翰 `u-lin` | 超級管理員 | 慈濟（成員）、光復福安宮志工隊（管理員） |
| `gov` | 吳政憲 `u-wu` | 政府 | 花蓮縣政府災防辦（管理員） |
| `ngo-admin` | 黃曉芳 `u-huang` | 非政府組織 | 壯闊台灣（管理員）、慈濟（成員）、花蓮縣政府災防辦（成員） |
| `ngo-member` | 李國豪 `u-lee` | 非政府組織 | 壯闊台灣（成員）、馬太鞍溪志工聯隊（成員，該隊停權中） |
| `auditor` | 張育成 `u-chang` | 資料檢核員 | 台灣世界展望會（成員） |
| `off` | 結束預覽，回到預設（超級管理員） | | |

例：`任務管理 Ticket Management.html?as=auditor`

- 同一個瀏覽器分頁裡換頁會**一直保持**這個角色（存在 `sessionStorage`），關掉分頁就結束。
- 預覽中左下角有一顆深色小標籤「👁 角色預覽：○○」，點它結束預覽。
- 也可以直接給 persona id，例如 `?as=u-chen`（陳小傑，只有一個身份，身份切換器不會出現）。
- 實作在 `js/admin/shell/wg-event.js` 的 `WG_PREVIEW_ROLES`。**正式版沒有這個機制**，身份來自登入（GraphQL `me`）。

⚠️ 一個人可能有好幾個身份（一人多隊）。右上角頭像選單的「切換身份」是**正式功能**，切過去之後平台角色會跟著所屬團隊變（2026-08-14：加入政府隊＝政府、加入 NGO 隊＝非政府組織）。上表是每個人**預設身份**的樣子。

## 實作時要注意

- **權限判斷讀「目前身份」的平台角色**（`wgActingPlatformRole()`），不是讀人身上的 `rbac`。同一個人切換身份後，導覽與按鈕要跟著變。
- **不 render 和唯讀是兩件事**：導覽、圈選按鈕這類「沒權限」用不 render；任務管理「全部單位」裡別隊的單是看得到但唯讀。不要混用。
- 前端隱藏只是體驗，**後端一定要再擋一次**。尤其：站點聯絡電話（公開 API 不得回傳）、任務單聯絡資訊（只給有 `ticket.view_history` 的人與承接該單需求的志工）。
- 有幾處和 Notion 權限矩陣刻意不同（例如資料檢核員可審核站點、政府只能核准不能退回），各功能文件裡標了 ⚠️，後端要配合。
