# 互助地圖（Mutual Aid Map）

> 原型：`Design/後台/互助地圖 Mutual Aid Map.html`；最新的樣子看原型網站 <https://wan-guard-prototype.sucrelin-design.workers.dev/%E4%BA%92%E5%8A%A9%E5%9C%B0%E5%9C%96%20Mutual%20Aid%20Map>（右上角「原型 · 角色視角」選超級管理員，1440 寬）
> 程式：`js/admin/map/*`、危險區樣式 `js/shared/wg-hazard.js`
> 正式版：`Frontend/apps/admin/src/app/(portal)/map/` ＋ `Frontend/libs/modules/src/map/`
> 正典：`MAP-FEAT-002` 責任區與危險區（AC-01〜AC-09、Q1〜Q6）；規則編號 `MAP-ZD-*`、`MAP-*-1xx` 見程式註解

## 這頁在做什麼

政府與平台管理者在地圖上**圈出區域**，告訴所有人「哪裡危險」「這一區交給誰」「這裡有什麼」。
責任區一圈下去，區內的任務單就一次指派給負責的團隊 —— 這是本頁最重要、也最危險的動作。

地圖上同時看得到：任務單（圓點，顏色＝優先級）、資源站點（深色方塊）、已圈的區域。

## 三種區域

| | 危險區 `hazard` | 責任區 `assign` | 標示區 `mark` |
|---|---|---|---|
| 用途 | 提醒大家不要進入 | 交給團隊負責，區內任務單歸他們 | 只標位置，不派團隊 |
| 負責團隊 | 不派 | **必填，可以好幾個**（🔒 11-02），最後一個不能移除 | 不派 |
| 樣式（🔒 10-23） | 橘白斜紋（固定，`wg-hazard.js`） | **靛 #4338CA** | **綠 #15803D** |
| 前台看不看得到（🔒 10-16；責任區 🔄 11-03） | **一律公開，沒有開關** | **只給登入的人看**，沒登入整個看不到；沒有開關 | 二擇一：只給後台看／公開，預設只給後台 |
| 拿掉的動作（🔒 11-02） | **「解除危險區」** | 「刪除區域」 | 「刪除區域」 |
| 例子 | 堤防潰口、土石流警戒 | 大平村交給慈濟基金會 | 志工休息區、集合點 |

- 🔒 危險區**不會自動到期**，要有人按「解除危險區」（2026-09-26，推翻 AC-06 的 24 小時）。按下去的意思是「危險已經過去」，所以不叫「刪除」——「刪除」聽起來像畫錯了。
- 🔒 **沒有「升為危險區」**（11-02）：危險區就是一開始選「危險區」畫出來的；標示區後來變危險，就另外畫一個危險區。標示區、責任區、危險區之間不互轉成危險區。
- 🔒 **責任區只指派給非政府組織隊**（Carol 11-03，BE-RBAC-3）：政府隊本來就看得到全部任務單，不需要責任區。⚠️ 原型的團隊清單還列著政府隊，還沒改。
- 🔒 **區域顏色照類型固定（2026-10-23）**：後端 `work_zones` 沒有顏色欄位，所以**不存顏色、不給人選色**，前後台都用 `wgZoneColor(kind)`（正式版 `PUBLIC_ZONE_COLORS`）。兩色都避開任務單的優先級色與危險區的橘。已知代價：相鄰的責任區同色，靠邊線與名稱標籤分辨。
- 🔒 **區域名稱最多 10 個字**（ZONE-NAME-101，見下方「前台地圖上的區域」）。

- 🔒 **MAP-LAYOUT-101 地圖鋪滿**：地圖與右側面板貼滿內容區，不留邊、沒有外框圓角。手機地圖在上、面板在下，整頁可捲（WG-RWD-107）。

- 🔒 **MAP-LABEL-101 區域名稱標籤**：跟前台同一種「類型・名稱」（`責任區・光復鄉 大平村`），白底、淡灰細框、12px 粗體；危險區框線橘色。負責團隊**不寫在標籤上**（右側清單與詳情有寫），標籤短才不會蓋住標點。

### 左上摘要列＋篩選（`map-filter.jsx`）

- 🔒 **MAP-FILTER-101**：收起、打開都**固定 424px 寬**（344px 時摘要加上「清除」「篩選」排不下，「篩選」會掉到第二行；寬度固定也不會一打開就跳一下）。右邊留給縮放鈕，窄螢幕以 `maxWidth` 收在地圖裡。分隔用 3px 小圓點，不用全形「·」（在 Noto Sans TC 佔 16px）。
- 🔒 **MAP-FILTER-102**：「N 張未指派」**0 也照樣顯示**（0 本身就是答案），但 0 用一般的淡色字，**有未指派的單才用橘色** —— 0 用橘色會讓人以為有事要處理。
- 篩選鈕照共用按鈕 **BTN-109〜111**（`libs/ui` 的 `Button variant="neutral" size="sm"`）：條件數用 `count`（小膠囊，不要寫「篩選 1」）、帶 `aria-expanded`、打開時淡橘底橘框。「清除」用 `variant="ghost" size="sm"`。寫法可照 `libs/modules/src/admin/shared/toolbar-search.tsx`。

## 前台地圖上的區域（🔒 2026-10-23）

- **名稱標籤一直顯示**，內容是「類型・名稱」（`責任區・光復鄉 大平村`）。不只放在滑過才出現的提示裡 —— 前台多在手機上用，手機沒有滑過。
- 🔒 **標籤不可以蓋住區域本身**：休息區、集合點這種區域都很小。每次縮放後量區域在畫面上的像素大小，❌ 不要用縮放級距寫死。擺放方式見下一節 ZONE-LABEL-102。
- 標籤壓在站點／任務標記底下（標記一定要點得到）。
- 🔒 **只有標籤可點**（`ZONE-CLICK-101`）：點標籤跳出類型・名稱、**負責：團隊**（只有責任區；責任區本身只有登入的人看得到，見下一條）、備註。**區域本身不可點**（`interactive: false`），點在區域裡會穿到地圖，照常出現「在這裡新增」—— 責任區常常是整個鄉。
- 🔄 **沒登入的人整個看不到責任區**（`ZONE-TEAM-101`，2026-11-03 Carol；推翻 10-23「前後台都公布被指派的組織」）：範圍、名稱、負責團隊都不給。理由：被指派的政府與 NGO 不希望責任區的範圍公開。危險區照舊公開；標示區照它的開關；登入的人看到的不變。
  - 正式版由**後端**擋：`areas` 對沒登入的人不回責任區，連 `pageInfo.totalCount` 都不算（PR #268，ADR-311 第 8 點已改）。前端不用自己藏
  - ❌ 不可以：資料照樣給訪客、只在畫面上不畫 —— 開發者工具一看就看得到
  - 前台圖層面板（`public-zones`）：登入時叫「責任區與標示區」、說明「團隊負責的範圍，和志工休息區、集合點等」；**沒登入時改叫「標示區」、說明「志工休息區、集合點等」，下面多一行淡色小字「責任區要登入才看得到」**（不然訪客會以為這一場沒有責任區）。🚨 訪客版文字是設計端擬的
  - 原型：`前台/js/site/site-data.js` `queryPublicZones`（訪客濾掉責任區）、`site-route.js` `OVERLAY_LAYER_CONFIG['public-zones']` 的 `guestLabel`／`guestDescription`／`guestNote`、`site-map.jsx` 圖層面板

### 標籤避讓與名稱長度（🔒 2026-10-24）

- 🔒 **ZONE-LABEL-102 區域標籤找空位**：格子數字與圖釘不動、一律優先；標籤排隊（危險區先，其他依區域在畫面上的面積由小到大），每張依序試「區域內 5×5 點（放得下才試，離中央近的先）→ 正下方 → 正上方 → 右側」，避開數字、已放的標籤、浮在地圖上的按鈕（`elementFromPoint`）與畫面外；都不行就只畫區域不寫字。縮放完、格子／圖釘重畫完都重算。⚠️ 藏起來的標籤點不到（ZONE-CLICK-101），要放大
- 🔒 **ZONE-NAME-101 區域名稱最多 10 個字**：Unicode code point（JS `[...s].length`、Python `len`、PostgreSQL `char_length`），中英數標點空白都算 1，先 trim。不要用 `s.length`（罕用字如「𥕢」算 2）、不要用 `<input maxLength>`（UTF-16、中文輸入法選字中被截、貼上默默砍掉）。超過 10 字的舊資料顯示前 9 字＋「…」，點標籤或滑過看全名

## 核心流程

**圈選新區域**（只有超級管理員與政府隊有這顆按鈕）

1. 按「圈選新區域」→ 在地圖上點出多邊形頂點。
2. 即時預覽：區內有幾張任務單、幾個站點（AC-02）。**超過 100 張**（`MAP_HIGH_VOLUME`）顯示高量警示。自我相交的形狀**不能送出**並說明原因（AC-08）。
3. 填資料：先選種類（三張卡片），再填名稱、說明、負責團隊（責任區必填）、標示區要不要公開。
4. 可以**退回改範圍**，已填的資料不會消失。
5. 責任區送出前分項列出：未指派的、**已指派給別隊的**（AC-07 要警示，會被改掉）、已在本隊的。
6. 送出後 5 秒內可完整復原（AC-03，`MAP_UNDO_SECONDS`），復原也記進操作紀錄。

**編輯邊界**（🔒 正典 Q4，2026-08-27 裁示）

- 改大：新進入區內且**未指派**的單 → 指派給本區團隊。
- 改小：掉出去、原屬本區團隊的單 → **歸屬不動**，掛「待複核」（`reviewZoneId`），在區域詳情裡看得見、可清除。

**刪除區域／解除危險區**：🚨 **不會**把任務單的歸屬收回（`MAP-ZD-147`，設計端定，未經裁示）。確認視窗：危險區寫「解除「名稱」？」＋「危險區會從地圖上移除，前台也看不到。只有按下後的 5 秒內可以復原。」，按鈕「解除」；其他寫「刪除「名稱」？」，按鈕「刪除」。提示訊息「已解除…」／「已刪除…」。

**寫給前台**：危險區、責任區一律寫給前台地圖；標示區看開關（`mapToPublicZone`）。責任區**帶負責團隊**，但只給登入的人（沒登入整個不給，`ZONE-TEAM-101`，見上）；不帶顏色（前台照類型算）；不帶區內任務單歸屬。

## 🔒 篩選是「看的方式」，不是「選的方式」（MAP-ZD-128）

區域的計數與批次指派**一律吃完整清單**，不吃篩選結果。
例：篩選只顯示「生命危急」，圈一個責任區 → 區內**所有**優先級的單都會被指派。
不這樣做，使用者會以為自己只指派了看得到的那幾張。這是最容易被「優化」掉的規則，**請不要改**。

## 資料形狀（原型）→ 後端對照

一筆區域：

```js
{ id, kind: "hazard" | "assign" | "mark", name,
  ring: [[lat, lng], ...],          // Leaflet 順序；送後端前轉 GeoJSON [lng, lat]
  team,                              // 原型只存一個；正式版責任區可以好幾個團隊（11-02），其餘 null
  note, status: "active" | "expired",
  createdBy, createdAt,
  color,                             // 原型內部用；後端不存，一律 wgZoneColor(kind)
  publicVisible }                    // 只有標示區用得到；危險區一律公開、責任區只給登入的人
```

| 原型 | 後端（`main`） |
|---|---|
| 責任區／標示區的範圍 | ERD `work_zones(uuid, name, geometry MultiPolygon SRID 4326, created_by, …, delete_at)` |
| 責任區的團隊 | ERD `team_zone_assign(team_uuid, zone_uuid)`，一區可以多隊 |
| 危險區 | GraphQL `hazardousZones(bounds)`／`hazardousZone(uuid)`（`HazardousZoneType`：`name, geometry, status, informationSource, note`） |
| 地圖上的任務單 | `tickets(bounds)`；本頁經 `mapBuildTickets()` 取 `TK_TICKETS` 中**有座標的**單（含前台報案） |
| 地圖上的站點 | `stations(bounds)`；本頁的 `MAP_STATIONS` 目前是空陣列，正式版與資源站點管理讀同一份 |

## 實作陷阱

- **篩選不影響指派**（見上）。
- 點在邊界上算「在區內」（`pointInPolygon` 刻意這樣寫）：災防寧可多框一張單，不要漏一張。
- 自我相交要在**畫的當下**就擋，不是送出時才報錯。
- 正典 AC-01 還要求矩形／圓形／自由曲線／點危害，原型**只做了多邊形**。
- 面積 `areaKm2` 是等距圓柱投影的粗算，只能拿來顯示，不能拿來做任何判斷。
- 後台區域樣式不要直接改前後台共用的 `getPublicZoneStyle`（見「地圖上區域的畫法」）。
- 原型每次載入會把要公開的區域整份寫回 `wg.bridge.publicZones`；頁面上沒有區域時會清空前台的區域圖層 —— 這是預期行為。
