# 找不到這一頁（404）—— 前台與後台

> 最後更新：2026-10-20（光復寶寶改成會動、以圖為主）· 分支 `sucrelindesign`
> 後台另有「沒有權限訪問此頁」（403），同一支元件，見 [沒有權限此頁.md](沒有權限此頁.md)
> 標 🔒 的是已裁示；標 🚨 的是設計端先定、**尚未經團隊裁示**，實作前請先確認。

## 做什麼

使用者走到平台裡**不存在的網址**時（打錯字、舊的分享連結、已移除的頁面），平台自己顯示的畫面。
前台、後台各一頁，**畫面本體是同一支元件**。

| 原型頁 | 外殼 | 檔案 |
|---|---|---|
| `前台/前台找不到頁面 Site Not Found.html` | 前台外殼（`SiteShell`，`module="notfound"`） | 頁面本身 ＋ `js/shared/wg-notfound.jsx` |
| `後台/後台找不到頁面 Not Found.html` | 後台外殼（`WGShell`，`active="notfound"`） | `js/admin/shell/wg-notfound-page.jsx` ＋ `js/shared/wg-notfound.jsx` |

`js/shared/wg-notfound.jsx` 在 `前台/` 與 `後台/` 各一份，**內容相同**，改一邊要同步另一邊。

## 畫面組成

```
[ 外殼：緊急公告橫幅、頂欄、側欄 —— 照常顯示 ]
        光復寶寶舉著「404」的牌子（會動） js/shared/wg-mascot.jsx  mood="lost"
        找不到這一頁                   標題（置中）
        一句說明                       前台／後台各自傳入（lead，置中）
        ┌ 下一步 ┐ ┌ 下一步 ┐ ┌ 下一步 ┐  卡片，最小觸控高度 44px
```

## 光復寶寶動畫（2026-10-20，404／403 共用）

🔒 2026-10-20 Sucre：「更有活力的方式呈現 404 以及 403，做成小動畫以圖片為主軸」。

| | 404 `mood="lost"` | 403 `mood="stop"` |
|---|---|---|
| 進場 | 從上方掉進來、彈一下 | 從小彈出來 |
| 循環 | 左右張望（眼睛跟著看）、眨眼、汗滴往外飛、兩個問號往上飄 | 每 3.6 秒搖頭說不、把牌子往前推、旁邊鎖頭跳一下；眨眼、汗滴 |
| 一輪 | 3.6 秒（汗滴 2.4 秒） | 3.6 秒 |

- **元件**：`js/shared/wg-mascot.jsx` 的 `WGMascot`（`mood`、`code`、`width`）。前台、後台各一份，**內容相同**。
- **做法**：原插圖 SVG 的路徑原封不動拆成幾組（身體＋臉、牌子＋手、汗滴、影子），用 CSS `@keyframes` 動；**沒有用任何動畫套件**。牌子上的字畫在網頁裡，吃得到 Nunito。
- 🔒 **系統設定「減少動態效果」時全部靜止**（`@media (prefers-reduced-motion: reduce)`）。
- 🚨 **點牠會跳一下**（彩蛋）。是 `<button>`，鍵盤按得到，`aria-label` 是「404」／「403」。
- 🚨 版面改成**以圖為主**：圖 200–260px、標題與說明置中。動作、節奏、鎖頭圖是設計端定的。
- `wg-notfound.jsx` 沒載入 `wg-mascot.jsx` 時會退回靜態圖（`assets/mascot/guangfu-baby-404.svg`），不會壞。
- **獨立動畫檔**：`assets/mascot/動畫/guangfu-baby-404-anim.svg`、`-403-anim.svg`。純 SVG＋CSS，約 13KB，`<img src>` 直接會動，字已轉外框（各平台一致）。正式版若不想搬 JSX，**直接用這兩個檔最省事**（但就沒有點了會跳）。

## 不在這一頁處理

- ⚠️ **任務單或站點已被刪除／結案**，有人點了舊的分享連結（例：`/map/...?selected=tk-123`）。網址本身是對的、只是那筆資料不在了 —— 那是地圖／列表裡的**內容狀態**，應在詳情位置說明「這筆已不存在」，不是整頁 404。**尚未設計。**

## 正式版實作建議（⚠️ 前端決定）

正式前端是 Next.js App Router（`Frontend/apps/demo/src/app/`），目前沒有任何 `not-found.tsx`。
要讓前台與後台的 404 各自套上自己的外殼，常見做法是：

- `app/(site)/[...notFound]/page.tsx` 與 `app/admin/[...notFound]/page.tsx` 呼叫 `notFound()`
- 搭配 `app/(site)/not-found.tsx`、`app/admin/not-found.tsx`，各自在自己的 layout 裡渲染
- 只放根目錄的 `app/not-found.tsx` 的話，不會帶到前台或後台的 layout（外殼會消失，違反規則 1）

這是建議，不是規格；確切寫法請依 Next.js 版本與現有路由結構決定。

## 實作陷阱

- **SVG 牌子上的字**：靜態的 `guangfu-baby-404.svg` 的「404」是 `<text>`，用 `<img>` 載入時讀不到網頁字型。2026-10-20 起畫面改用 `WGMascot`（字畫在網頁裡）；`assets/mascot/動畫/*-anim.svg` 的字已轉外框。
- **SVG 裡的 CSS transform**：每個要動的 `<g>` 都設了 `transform-box: fill-box`，旋轉才會繞著自己轉；**不要在同一個 `<g>` 上同時放 `transform` 屬性和 CSS 動畫**（CSS 會蓋掉屬性），鎖頭就是外層 `<g transform>` 定位、內層 `<g>` 動。
- **影子用 `fill-opacity` 不用 `opacity`**：動畫會改 `opacity`，放在屬性上會被蓋成全黑。
- 原插圖引用的陰影圖 `光復寶寶2-1.png` 沒有提供，交付的 SVG 已拿掉那一層。
- 原型的 `text/babel` 腳本不可用物件 rest 解構（Babel standalone 會在全域宣告 `_excluded`，多支腳本撞名白畫面）。正式版無此問題。
