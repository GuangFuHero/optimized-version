# 後台原型 — 更新說明

**分支：** `sucrelindesign`
**本次更新：** 2026-10-02（首次交付後台）

## 本次交付的四頁

| 頁面 | 重點 |
|---|---|
| 資源站點管理 | 列表／地圖兩種視圖；審查佇列；匯入、匯出；站點群（母站底下掛子站）。表頭標「等後端開欄位」的兩欄（管運狀態、指派 Team）後端還沒有欄位 |
| 緊急公告 | 只有**超級管理員與政府**能發布（裁示 D-3，覆蓋正典 EA-FEAT-001 AC-06）。其他身份看不到這一項導覽，但看得到公告橫幅 |
| 志工行前資訊 | 整份只有**一塊 Markdown 內容**，災害類型只是建立時的範本；可勾項目由作者標記。編輯權限同緊急公告（超級管理員／政府） |
| 成員管理 | 「團隊」與「成員與權限」兩個分頁。核准前台的平台角色申請後，會自動跳到「成員與權限 → 全平台人員」並標示那一列 |

## 角色與導覽（四頁共用 `js/admin/shell/nav.js`）

導覽項依「目前身份」**直接不 render**，不是灰掉：

| 導覽項 | 誰看得到 |
|---|---|
| 緊急公告、志工行前資訊 | 超級管理員、政府 |
| 成員與權限 | 超級管理員 |
| 資料檢核 | 超級管理員、資料檢核員 |
| 團隊 | 資料檢核員以外的所有身份 |

用頂端「原型 · 角色視角」列切換角色就能看到差異（那一列只存在於原型）。
